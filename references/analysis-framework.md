# 六大分析模块详细框架

## 模块 1：市场状态判断（market-state）

**核心目标**：判断市场处于哪个阶段（进攻 / 震荡 / 防守 / 切换）以及行情真实质感（健康还是脆弱）。

### 必查指标

| 指标 | 数据来源 | 判断阈值 |
|---|---|---|
| 三大指数涨跌 | 行情数据 | 越偏成长跌幅越深 → 防御格局 |
| 区间振幅 | 最高 - 最低 | > 5% = 高波动 |
| 成交额 | 两市合计 | > 2 万亿 = 活跃；1.4-1.8 万亿 = 存量博弈；< 1.2 万亿 = 冰点 |
| 涨跌家数 | 涨跌分布 | 上涨占比 > 60% = 普涨（健康）；< 30% = 普跌（弱势） |
| 涨停/跌停 | 涨跌分布 | 涨停 > 80 = 情绪活跃；跌停 > 30 = 恐慌 |
| 涨跌幅分布 | 分区间统计 | 尾部跌幅厚（跌超 5% > 500 家）= 个股杀伤 > 指数 |

### 行情性质四分类

1. **全面扩散（健康）**：80%+ 行业上涨、个股普涨 → 进攻
2. **局部抱团（风险）**：少数赛道独涨、其他普跌 → 精选
3. **弱修复反弹（持续性弱）**：超跌反弹、量能不济 → 观望
4. **普遍转弱（需防）**：广度恶化、防御板块走强 → 防守

### 关键原则

- **广度恶化常先于指数回落**——指数还在涨但广度先掉头 = 脆弱信号
- 别把"指数没跌"等同于"市场健康"——少数权重撑住的指数最危险
- 状态不清晰时敢说"切换中 / 震荡中"
- 不只看单日异动——看阶段性广度变化

## 模块 2：风格与板块比较（sector-comparison）

**核心目标**：横向比较板块（不是逐个单独写），必须给排序。

### 分析六步

1. **核心逻辑对比**：每个板块当下为什么买、未来靠什么涨（不是列公司名单）
2. **交易位置对比**：低位预热 / 启动确认 / 主升演绎 / 高位拥挤 / 退潮修复
3. **催化强度对比**：硬催化（业绩/政策/订单）vs 软催化（情绪/海外映射）
4. **资金偏好对比**：成交额 / 龙头强度 / 中军承接 / 机构参与度
5. **拥挤度评估**：逻辑好但过度拥挤 = 短期风险大
6. **必须给排序**：短期优先级 / 中期优先级 / 追踪还是等待

### 申万一级行业速查

| 类别 | 行业 |
|---|---|
| 进攻 | 电子、计算机、通信、传媒、电力设备、国防军工 |
| 防御 | 银行、石油石化、煤炭、食品饮料、交通运输、公用事业 |
| 消费 | 食品饮料、商贸零售、社会服务、美容护理、纺织服饰 |
| 周期 | 有色金属、钢铁、基础化工、建筑材料、机械设备 |
| 医药 | 医药生物、医疗服务、生物制品 |
| 成长 | 电子、计算机、通信、传媒、电力设备 |

### 避坑

- 不是"逐个分别写"是"横向比较"
- 不只看逻辑强弱，必须结合位置和交易性
- 板块轮动是结果不是预测——别用后视镜推断"下一个会是哪个"

## 模块 3：主线识别（market-mainline）

**核心目标**：识别真主线，不把一日脉冲误判为主线。

### 四种热度区分

| 类型 | 特征 | 操作含义 |
|---|---|---|
| **真主线** | 连续性强、龙头明确、扩散清晰 | 可跟踪做波段 |
| **次级热点** | 当日强势但持续性待验证 | 观察为主 |
| **脉冲题材** | 一日游、缺乏龙头 | 不参与 |
| **跟风分支** | 主线带动、独立性弱 | 只做主线不做分支 |

### 情绪周期判断

冰点 → 修复 → 主升 → 高位震荡 → 退潮

**情绪温度计**：连板高度 + 炸板率 + 涨停数 + 跌停数 + 高位股次日溢价

### 主线持续性评估

| 等级 | 条件 |
|---|---|
| 强 | 产业逻辑扎实 + 催化连续 + 资金合力明确 |
| 较强 | 逻辑清晰 + 催化明确，资金未完全合力 |
| 一般 | 逻辑合理但催化不连续 |
| 弱 | 一日脉冲 / 跟风分支 |

## 模块 4：资金面分析（fund-flow）

### 必查维度

| 维度 | 数据 | 判断阈值 |
|---|---|---|
| 主力资金 | 行业/市场净流入流出 | 净流出 > 1000 亿/周 = 系统性撤退 |
| 融资余额 | 日度/周度变化 | 连降 > 3 日 = 杠杆降温 |
| 两融差额 | 与 20 日均值比较 | 低于均值 = 做多意愿弱 |
| ETF 净流入 | 股票型 ETF | 大额净流入 = 中长期资金承接 |
| 行业资金流向 | 哪些行业流入/流出 | 确认板块轮动方向 |

### 信号组合判读

| 主力资金 | 融资余额 | ETF | 判读 |
|---|---|---|---|
| 流出 | 降 | 流入 | 存量出清 + 中长期建仓 → 磨底 |
| 流出 | 降 | 流出 | 全面失血 → 继续防守 |
| 流入 | 升 | 流入 | 增量进场 → 可进攻 |
| 流出 | 升 | 流入 | 分歧期 → 等方向 |

## 模块 5：宏观传导链（macro-transmission）

**核心目标**：建立"宏观变量 → 中间变量 → 行业盈利 → 市场风格"完整传导链。

### 传导模板

```
宏观变量 → 中间变量 → 一阶受益行业 → 二阶受益行业 → 代表性方向
```

### 常见传导路径

| 宏观变量 | 中间变量 | 一阶受益 | 二阶受益 |
|---|---|---|---|
| 利率下行 | 估值中枢上移 / 融资成本降 | 成长股、券商 | 设备、零部件 |
| 利率上行 | 估值压缩 / 风险偏好降 | 银行、保险 | 高股息防御 |
| 汇率贬值 | 出口竞争力提升 | 外贸制造、航运 | 上游材料 |
| 财政发力 | 基建投资增加 | 建材、工程机械 | 钢铁、有色 |
| 货币宽松 | 流动性增加 | 风险资产整体 | 成长弹性品种 |

### 避坑

- 经济数据与股价表现时常背离——传导不是直线
- 市场往往提前反应——数据公布时可能已充分定价 / 反向交易
- 政策传导存在时滞和失效风险
- 央行/美联储决议：标注本地时间 + 北京时间双标

## 模块 6：估值定位（valuation）

| 指标 | 来源 | 偏高阈值 | 偏低阈值 |
|---|---|---|---|
| 全 A PE (TTM) | 研报 / Wind | > 60% 分位 | < 40% 分位 |
| 全 A PB (LF) | 研报 / Wind | > 60% 分位 | < 40% 分位 |
| 风格指数 | 国证价值 vs 国证成长 | 剪刀差 > 5pct = 极端分化 | — |
| 大小盘 | 上证 50 vs 中证 2000 | 差值 > 5pct = 极端占优 | — |

PE 偏高 + PB 偏低 = 盈利端承压（利润下滑拖累 PE）
