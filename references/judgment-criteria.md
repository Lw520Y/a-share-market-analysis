# 判断标准与决策树

## 一、市场档位决策树

```
量能 > 2万亿 + 涨跌占比 > 60% + 融资余额上升
  → 进攻档（可加风险敞口、追主线）

量能 1.4-1.8万亿 + 涨跌占比 30-60% + 广度剧烈摆动
  → 震荡档（精选个股、控制仓位、做短不做长）

量能 < 1.4万亿 + 涨跌占比 < 30% + 防御板块走强
  → 防守档（减仓 + 防守板块 + 现金为王）

指标矛盾（如指数涨但广度差）
  → 切换档（减少新进场、等结构清晰）
```

## 二、反转确认三信号

**单日反弹 ≠ 反转**。需**三信号共振**才能确认反转：

| 信号 | 条件 | 当前示例 |
|---|---|---|
| 量能 | 成交额稳定站上 2 万亿（连续 3 日以上） | 1.4-1.8 万亿 → ❌ |
| 杠杆 | 融资余额止跌回升（结束连降） | 6 连降 → ❌ |
| 广度 | 上涨家数占比连续 3 日 > 50% | 35%（11-03）→ ❌ |

**任一信号缺失 → 维持"震荡磨底"判断。**

## 三、主线持续性评估矩阵

| 等级 | 产业逻辑 | 催化连续性 | 资金合力 | 操作 |
|---|---|---|---|---|
| 强 | 扎实 | 连续 | 明确 | 可跟踪做波段 |
| 较强 | 清晰 | 明确 | 未完全合力 | 逢低关注 |
| 一般 | 合理 | 不连续 | 一般 | 观察为主 |
| 弱 | 一般 | 一日游 | 无 | 不参与 |

## 四、风格切换信号

| 信号 | 预示 |
|---|---|
| 银行/红利连续 3 日回调 + 成长放量 | 资金回流成长，风格切换 |
| 成长板块融资余额转升 | 杠杆资金重新加仓成长 |
| 成长板块 ETF 转净流入 | 中长期资金布局成长 |
| 上涨家数占比从 < 30% 回升至 > 50% | 赚钱效应扩散 |
| 防御板块连续走强 + 成长新低 | 避险情绪升温，继续防守 |

## 五、量能分档

| 日成交额 | 分档 | 含义 |
|---|---|---|
| > 2.5 万亿 | 极度活跃 | 情绪亢奋，注意过热风险 |
| 2.0-2.5 万亿 | 活跃 | 增量资金入场，可进攻 |
| 1.4-2.0 万亿 | 存量博弈 | 跷跷板行情，精选个股 |
| 1.0-1.4 万亿 | 低迷 | 观望为主 |
| < 1.0 万亿 | 冰点 | 极度悲观，反而是底部信号 |

## 八、风险信号

出现以下任一信号时**降低仓位 / 切换防守**：
- 广度恶化先于指数回落（指数涨但上涨家数占比下降）
- 成交额连续 3 日萎缩
- 融资余额连续 5 日下降
- 跌停数 > 30 家
- 防御板块与成长板块剪刀差 > 10pct
- 高位股大面积跌停
